# 💣 지뢰찾기 (Minesweeper)

설치 없이 브라우저에서 바로 실행되는 단일 HTML 파일 지뢰찾기 게임입니다.

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 빌드나 서버가 필요 없습니다.

## 기능

- **시작 메뉴**: 게임 시작 / 기록 보기 / 설정
- **난이도**: 초급(9×9, 지뢰 10), 중급(16×16, 지뢰 40), 고급(30×16, 지뢰 99)
- **첫 클릭 안전**: 첫 클릭한 칸과 그 주변에는 지뢰가 없습니다.
- **추측 없는 판 생성**: 첫 클릭 후 논리만으로 풀 수 있는 판이 나올 때까지 보드를 다시 만듭니다. 설정에서 끌 수 있습니다.
- **최고 기록**: 난이도별 상위 5개 기록(시간, 날짜)을 저장하고, 신기록이면 알려줍니다.
- **깃발 색 설정**: 프리셋 5색 또는 원하는 색을 직접 선택할 수 있습니다.
- **자동 열기(chord)**: 숫자 칸 주변의 깃발 수가 숫자와 같을 때 그 숫자 칸을 클릭하면 나머지 주변 칸이 열립니다.

## 조작법

| 동작 | PC | 모바일 |
|---|---|---|
| 칸 열기 | 좌클릭 | 탭 |
| 깃발 꽂기/빼기 | 우클릭 | 길게 누르기 |
| 주변 자동 열기 | 숫자 칸 좌클릭 | 숫자 칸 탭 |
| 다시 시작 | 상단 이모지 버튼 | 상단 이모지 버튼 |

## 저장 데이터

기록과 설정은 브라우저의 `localStorage`(`minesweeper.records`, `minesweeper.settings`)에 저장됩니다. 브라우저 데이터를 지우면 함께 삭제되며, 다른 브라우저와는 공유되지 않습니다.
